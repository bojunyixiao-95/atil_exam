题目：生成一个Book类（C++）

思路:1、根据题目提示+要求，做一个Book类，里面存书名、价格、库存。我可以把这三样数据都放在private中，外面不能直接改，也就是封装，这样安全。
2、然后在公有成员函数中先初始化书籍信息，防止里面出现随机乱码（注意有小数点的数字），然后用析构函数，（但因为题目要求的输入结果，且查询资料可知：string 会自动管理自己的内存，所以我选择将其注释掉）
3、然后就是用键盘读取并输入信息（input），注意用getline读取整行信息（精确度高些，不会因为书名有空格而读取错误）；用cin通过键盘输入数据。
4、输出信息：依据题目格式通过cout输出书籍信息。
5、最后便是入口函数int main执行程序。（使用指针调用成员函数，最后delete释放内存）
运行结果为：
输入：
C++入门
45.5
20

输出：
书名：C++入门
价格：45.5
库存：20
